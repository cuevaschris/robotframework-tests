# Robot Framework Tests - Swaglabs Test Suite

This repository contains automated UI tests for the **Swaglabs** (https://www.saucedemo.com/) application using the **Robot Framework**. The test suite is designed with a modular structure to ensure maintainability, reusability, and scalability.

## Project Overview

This project demonstrates a **Page Object Model (POM)** and **Keyword-Driven Testing** approach using Robot Framework with the **Browser** library (Playwright). The test suite covers the following features:

- **User Authentication**: Login functionality
- **Shopping Cart**: Adding/removing items
- **Checkout Process**: Multi-step checkout workflow
- **Data Validation**: URL and element state validation

**Technology Stack:**
- Robot Framework
- Playwright (Browser Library)
- Python 3.x
- FakerLibrary (for test data generation)
